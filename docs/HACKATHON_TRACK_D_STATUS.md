# Multimodal AI Hackathon 2026 · Track D status

Reviewed on 14 October 2026 against the Track D brief. The reviewed implementation is pushed to the public GitHub repository on `codex/track-d-submission-readiness`; `main` has not yet been updated. The prototype includes model-inferred course topic hierarchy, a new-learner baseline diagnostic, and a saved post-assessment report for weak topics and likely misconceptions. Synthetic multimodal and browser integration checks pass; the separate demo recording remains outside this checklist.

## Implemented in the prototype

- Course ingestion for PDF, PPTX, legacy PPT, and recordings. PDF/PPT/PPTX pages or slides retain provenance; legacy PPT converts to PPTX and PDF through LibreOffice with a slide-count check. Recordings transcribe locally. With Cerebras vision configured, up to 20 evenly spaced video frames are described, saved with uncertainty and timestamp, and indexed with the transcript.
- Provenance-preserving course chunks, keyword and default local semantic retrieval, and model-inferred major topics, subtopics, key concepts, prerequisite links, and per-chunk tags. Topic levels and parent links are visible in the course knowledge view. Deterministic tags remain available as a fallback.
- Tutor answers retrieve from the active course, require claim-level citation verification, open exact pages/slides/timestamps, and refuse when evidence is missing. Explicit tutor checks are graded and saved; ordinary chat does not alter mastery.
- Verified assessment bank with MCQ, short-answer, and numerical items; topics, difficulty, citations, and question version; deterministic MCQ/numerical grading; evidence-based short-answer grading; saved resumable attempts; exact/near-duplicate prompt rejection; and a completed-attempt report with weak topics, evidence-linked likely misconceptions, and recommended next steps. If model analysis is unavailable, the report clearly identifies unresolved knowledge gaps.
- Per-course local learner history, topic-level Bayesian Knowledge Tracing (BKT), uncertain-grade exclusion, assessment history, weak-topic targeting, insufficient-evidence display, and a one-click six-question baseline diagnostic for learners with no observations. Parameters and limitations are documented in [multi-source assessment](MULTI_SOURCE.md).
- Optional syllabus mapping, source-backed progress, recent mistakes, and a learning-history report.
- Setup, model boundary, retrieval, tutor, and demo walkthrough documentation. The GitHub repository `KM-in/pocketta-local` was checked through the GitHub repository API and reports `visibility=public`, with `main` as its default branch.
- Browser review of the inferred topic hierarchy and saved assessment report passed on synthetic course data. The cited 60-second video opened with loaded metadata at `currentTime=60` in a 61-second recording. The live configured-provider API check also verified diagram OCR, five inferred hierarchy entries, cited retrieval, a persisted assessment report, and frame citations at 0 and 60 seconds. The synthetic video used a hand-written transcript because no local Whisper runtime/model is installed. Current course data contains PDFs only. See [the integration report](evaluation/real-integration-checks.md).
- The latest regression gate passes: 146 backend tests, 47 frontend tests, Python compilation, clean dependency checks, and the production frontend build. The suites cover legacy PPT conversion, video frame sampling, saved assessment reports, fractional timestamp seeking after media metadata loads, and local embedding configuration and no-API-cost behavior.
- Embeddings now default to local FastEmbed. API keys alone cannot enable billable embeddings; `EMBEDDING_PROVIDER=api` is an explicit opt-in. The live synthetic retrieval smoke returns all six expected locations and rejects both unsupported queries at the local threshold of 0.80. Only two supported cases include semantic results; the other four pass via keyword fallback. See the saved [FastEmbed retrieval report](evaluation/live-retrieval-fastembed-2026-10-14.json). This is a narrow synthetic check, not a broad semantic-quality result.
